You accidentally pushed code directly to the main branch. What will you do?

- If the commit is already shared, I would avoid rewriting history and use
  git revert to create a new commit that undoes the changes. 
- If the commit has not been shared, I may use git reset and force-push after team
  agreement.

------------------------------------------------------------
You committed secrets/API keys accidentally. What will you do?

- I would immediately revoke or rotate the exposed credentials. 
- Then I would remove the secrets from the repository, force-push the cleaned
  history, and notify the team. 
- Secrets should never remain valid even if removed from Git.

------------------------------------------------------------
You accidentally deleted a branch. Can it be recovered?

- Yes. Git usually keeps references in reflog.

    git reflog

Find the commit hash and recreate the branch:

    git checkout -b branch-name <commit-hash>
